## 一、贝尔曼方程与价值函数

### 1.1 数学公式

**状态价值函数 V(s)**：
$$V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{t=0}^{\infty} \gamma^t R(s_t, a_t) \mid s_0 = s \right]$$

**贝尔曼方程**：
$$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R(s,a,s') + \gamma V^\pi(s')]$$

```python:70:107:verl/trainer/ppo/core_algos.py
def compute_gae_advantage_return(token_level_rewards: torch.Tensor, values: torch.Tensor, eos_mask: torch.Tensor,
                                 gamma: torch.Tensor, lam: torch.Tensor):
    """Adapted from https://github.com/huggingface/trl/blob/main/trl/trainer/ppo_trainer.py

    Args:
        token_level_rewards: `(torch.Tensor)` 形状: (bs, response_length)
        values: `(torch.Tensor)` V(s) 的估计，形状: (bs, response_length)
        eos_mask: `(torch.Tensor)` EOS mask，形状: (bs, response_length)
        gamma: `(float)` 折扣因子 γ
        lam: `(float)` GAE lambda 参数

    Returns:
        advantages: `(torch.Tensor)` 形状: (bs, response_length)
        Returns: `(torch.Tensor)` 形状: (bs, response_length)
    """
    with torch.no_grad():
        lastgaelam = 0
        advantages_reversed = []
        gen_len = token_level_rewards.shape[-1]

        # 核心循环：反向计算 TD 误差
        for t in reversed(range(gen_len)):
            # nextvalues 对应贝尔曼方程中的 V(s')
            nextvalues = values[:, t + 1] if t < gen_len - 1 else 0.0
            
            # δ_t = r_t + γV(s_{t+1}) - V(s_t)  ← TD误差
            delta = token_level_rewards[:, t] + gamma * nextvalues - values[:, t]
            
            # A_GAE(t) = δ_t + γλA_GAE(t+1)  ← GAE递归
            lastgaelam = delta + gamma * lam * lastgaelam
            advantages_reversed.append(lastgaelam)
        
        advantages = torch.stack(advantages_reversed[::-1], dim=1)
        
        # Returns = Advantages + Values 对应 V(s) 的更新
        returns = advantages + values
        advantages = verl_F.masked_whiten(advantages, eos_mask)
    return advantages, returns
```

## 二、GAE 优势估计

### 2.1 数学公式

**GAE 定义**：
$$A_{GAE}(s_t, a_t) = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l}$$

其中 \(\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)\)

### 2.2 代码实现

```python:70:107:verl/trainer/ppo/core_algos.py
# GAE 的递归实现（反向循环）
# 注意：代码中从后向前遍历序列

lastgaelam = 0  # 初始化累积的 GAE 值 A(s_{T})

for t in reversed(range(gen_len)):
    # t = T-1, T-2, ..., 0
    
    # 1. 获取下一状态的价值 V(s_{t+1})
    nextvalues = values[:, t + 1] if t < gen_len - 1 else 0.0
    
    # 2. 计算 TD 误差 δ_t = r_t + γV(s_{t+1}) - V(s_t)
    delta = token_level_rewards[:, t] + gamma * nextvalues - values[:, t]
    
    # 3. 累积 GAE: A_t = δ_t + γλA_{t+1}
    #    lastgaelam 存储的是 A_{t+1}
    #    更新后变成 A_t
    lastgaelam = delta + gamma * lam * lastgaelam
    
    # 4. 保存 A_t
    advantages_reversed.append(lastgaelam)

# 反转得到正确顺序
advantages = torch.stack(advantages_reversed[::-1], dim=1)
```

### 2.3 展开理解

假设序列长度为 4，γ = 0.9, λ = 0.95：

```
反向遍历顺序：     t=3 → t=2 → t=1 → t=0

t=3 (最后一个token):
    lastgaelam = δ₃
    
t=2:
    lastgaelam = δ₂ + 0.9×0.95×δ₃ = δ₂ + 0.855×δ₃
    
t=1:
    lastgaelam = δ₁ + 0.9×0.95×(δ₂ + 0.855×δ₃)
              = δ₁ + 0.855×δ₂ + 0.731×δ₃
    
t=0:
    lastgaelam = δ₀ + 0.9×0.95×A₁
              = δ₀ + 0.855×δ₁ + 0.731×δ₂ + 0.624×δ₃

这正好对应 GAE 公式！
A_GAE(t) = Σ (γλ)^l δ_{t+l}
```

## 三、GRPO 优势计算

### 3.1 数学公式

**GRPO 优势函数**：
$$A_i = \frac{r_i - \mu_G}{\sigma_G}$$

其中 G 是同一 prompt 生成的多个样本组，μ_G 和 σ_G 是组内均值和标准差。

### 3.2 代码实现

```python:110:156:verl/trainer/ppo/core_algos.py
def compute_grpo_outcome_advantage(token_level_rewards: torch.Tensor,
                                   eos_mask: torch.Tensor,
                                   index: torch.Tensor,
                                   epsilon: float = 1e-6):
    """
    Compute advantage for GRPO, operating only on Outcome reward 
    (with only one scalar reward for each response).
    
    Args:
        token_level_rewards: `(torch.Tensor)` 形状: (bs, response_length)
        eos_mask: `(torch.Tensor)` 形状: (bs, response_length)
        index: 标记每个样本属于哪个 prompt 组
    """
    response_length = token_level_rewards.shape[-1]
    
    # 1. 提取最终奖励（只在 EOS 位置有非零奖励）
    non_zero_mask = (token_level_rewards != 0)
    scores = (token_level_rewards * non_zero_mask).sum(dim=-1)  # (bs,)

    id2score = defaultdict(list)
    id2mean = {}
    id2std = {}

    with torch.no_grad():
        bsz = scores.shape[0]
        
        # 2. 按 index 分组
        # index[i] 表示第 i 个样本属于哪个 prompt 组
        for i in range(bsz):
            id2score[index[i]].append(scores[i])
        
        # 3. 计算每组的均值和标准差
        for idx in id2score:
            if len(id2score[idx]) == 1:
                # 只有一个样本时，标准差设为1（避免除零）
                id2mean[idx] = torch.tensor(0.0)
                id2std[idx] = torch.tensor(1.0)
            elif len(id2score[idx]) > 1:
                id2mean[idx] = torch.mean(torch.tensor(id2score[idx]))
                id2std[idx] = torch.std(torch.tensor([id2score[idx]]))
        
        # 4. 计算组内相对优势
        for i in range(bsz):
            # A_i = (r_i - μ_G) / σ_G
            scores[i] = (scores[i] - id2mean[index[i]]) / (id2std[index[i]] + epsilon)
        
        # 5. 扩展到所有 token（整个序列用同一个优势值）
        scores = scores.unsqueeze(-1).tile([1, response_length]) * eos_mask

    return scores, scores
```

## 四、PPO 策略损失

### 4.1 数学公式

**PPO CLIP 目标函数**：
$$L^{CLIP}(\theta) = \mathbb{E}_{s,a \sim \pi_{old}} \left[ \min \left( r_t(\theta) A_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t \right) \right]$$

其中 \( r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{old}(a_t|s_t)} \)

### 4.2 代码实现

```python:163:194:verl/trainer/ppo/core_algos.py
def compute_policy_loss(old_log_prob, log_prob, advantages, eos_mask, cliprange):
    """Compute PPO policy loss with clipping.

    Args:
        old_log_prob: `(torch.Tensor)` 旧策略的 log π_old(a|s)
        log_prob: `(torch.Tensor)` 新策略的 log π_θ(a|s)
        advantages: `(torch.Tensor)` 优势函数 A(s,a)
        eos_mask: `(torch.Tensor)` mask
        cliprange: (float) clip 范围 ε，通常为 0.2
    """
    # 1. 计算 log 概率差（对应 log r_t(θ)）
    # log(r_t) = log π_θ - log π_old
    negative_approx_kl = log_prob - old_log_prob
    
    # 2. 计算重要性采样比率 r_t = exp(log r_t)
    ratio = torch.exp(negative_approx_kl)
    
    # 3. 计算 KL 散度（用于监控）
    ppo_kl = verl_F.masked_mean(-negative_approx_kl, eos_mask)

    # 4. 策略损失的两个部分
    # 未 clip 的损失: -A × r_t
    pg_losses = -advantages * ratio
    
    # clip 后的损失: -A × clip(r_t, 1-ε, 1+ε)
    pg_losses2 = -advantages * torch.clamp(ratio, 1.0 - cliprange, 1.0 + cliprange)

    # 5. 取较大值（对应 min 函数）
    pg_loss = verl_F.masked_mean(torch.max(pg_losses, pg_losses2), eos_mask)
    
    # 6. 统计有多少比例被 clip 了（用于监控）
    pg_clipfrac = verl_F.masked_mean(torch.gt(pg_losses2, pg_losses).float(), eos_mask)
    
    return pg_loss, pg_clipfrac, ppo_kl
```

## 五、KL 散度约束

### 5.1 数学公式

**KL 散度**：
$$KL(\pi_{old} || \pi_{new}) = \sum_a \pi_{old}(a|s) \log \frac{\pi_{old}(a|s)}{\pi_{new}(a|s)}$$

**带 KL 惩罚的奖励**：
$$r_{KL}(s,a) = r(s,a) - \beta \cdot KL(\pi_{old} || \pi_{new})$$

### 5.2 代码实现

```python:91:121:verl/trainer/ppo/ray_trainer.py
def apply_kl_penalty(data: DataProto, kl_ctrl: core_algos.AdaptiveKLController, kl_penalty='kl'):
    """应用 KL 散度惩罚到奖励"""
    responses = data.batch['responses']
    response_length = responses.size(1)
    token_level_scores = data.batch['token_level_scores']
    batch_size = data.batch.batch_size[0]
    attention_mask = data.batch['info_mask'] if 'info_mask' in data.batch else data.batch['attention_mask']
    response_mask = attention_mask[:, -response_length:]

    # 计算 KL 散度
    if 'ref_log_prob' in data.batch.keys():
        # KL = log π_new - log π_ref
        kld = core_algos.kl_penalty(
            data.batch['old_log_probs'],  # 新策略
            data.batch['ref_log_prob'],   # 参考策略（相当于 old）
            kl_penalty=kl_penalty
        )  # (batch_size, response_length)
        kld = kld * response_mask
        beta = kl_ctrl.value  # 自适应 KL 系数
    else:
        beta = 0
        kld = torch.zeros_like(response_mask, dtype=torch.float32)

    # r_KL = r - β × KL
    # 这是核心公式！
    token_level_rewards = token_level_scores - beta * kld

    # 计算平均 KL（用于监控）
    current_kl = masked_mean(kld, mask=response_mask, axis=-1)
    current_kl = torch.mean(current_kl, dim=0).item()

    # 更新自适应 KL 控制器
    kl_ctrl.update(current_kl=current_kl, n_steps=batch_size)
    data.batch['token_level_rewards'] = token_level_rewards

    metrics = {'critic/kl': current_kl, 'critic/kl_coeff': beta}

    return data, metrics
```

### 5.3 自适应 KL 控制器

```python:28:44:verl/trainer/ppo/core_algos.py
class AdaptiveKLController:
    """
    Adaptive KL controller described in the paper:
    https://arxiv.org/pdf/1909.08593.pdf
    """

    def __init__(self, init_kl_coef, target_kl, horizon):
        self.value = init_kl_coef      # 当前 β 值
        self.target = target_kl        # 目标 KL 值
        self.horizon = horizon         # 时间跨度

    def update(self, current_kl, n_steps):
        target = self.target
        # proportional_error ∈ [-0.2, 0.2]
        proportional_error = np.clip(current_kl / target - 1, -0.2, 0.2)
        
        # 逐渐调整 β
        mult = 1 + proportional_error * n_steps / self.horizon
        self.value *= mult
```

### 5.4 KL 惩罚的作用

```
没有 KL 惩罚：
    新策略 → 可能完全偏离旧策略 → 崩溃

有 KL 惩罚（β > 0）：
    新策略 → 如果偏离太多，奖励会下降 → 被惩罚
             → 保持在合理范围内 → 稳定训练
```

```python:62:83:verl/utils/reward_score/qa_em.py
def extract_solution(solution_str):
    """Extract the equation from the solution string."""
    # 使用正则表达式提取 <answer>...</answer>
    answer_pattern = r'<answer>(.*?)</answer>'
    match = re.finditer(answer_pattern, solution_str, re.DOTALL)
    matches = list(match)
    
    # 如果没有匹配或只有1个匹配，返回 None
    # 如果有多个匹配（多次尝试），返回最后一个
    if len(matches) <= 1:
        return None
    
    return matches[-1].group(1).strip()
```

```python:19:33:verl/utils/reward_score/qa_em.py
def normalize_answer(s):
    """标准化答案用于比较"""
    def remove_articles(text):
        return re.sub(r"\b(a|an|the)\b", " ", text)

    def white_space_fix(text):
        return " ".join(text.split())

        return "".join(ch for ch in text if ch not in exclude)

        return text.lower()

    return white_space_fix(remove_articles(remove_punc(lower(s))))
```

```python:220:320:search_r1/llm_agent/generation.py
    rollings = gen_batch

    # 2. 主循环
    for step in range(self.config.max_turns):
        if not active_mask.sum():
            break
        
        # 3. 裁剪到有效长度
        rollings.batch = self.tensor_fn.cut_to_effective_len(
            rollings.batch,
            keys=['input_ids', 'attention_mask', 'position_ids']
        )
        
        # 4. 获取当前活跃的 batch
        rollings_active = DataProto.from_dict({
            k: v[active_mask] for k, v in rollings.batch.items()
        })
        
        # 5. 调用 LLM 生成
        gen_output = self._generate_with_gpu_padding(rollings_active)

        # 6. 后处理：停止在 </search> 或 </answer>
        responses_ids, responses_str = self._postprocess_responses(gen_output.batch['responses'])

        # 7. 执行动作（搜索或回答）
        next_obs, dones, valid_action, is_search = self.execute_predictions(
            responses_str, self.tokenizer.pad_token, active_mask
        )
        
        # 8. 更新活跃掩码
        curr_active_mask = torch.tensor([not done for done in dones], dtype=torch.bool)
        active_mask = active_mask * curr_active_mask
        turns_stats[curr_active_mask] += 1
        
        # 9. 处理观察结果
        next_obs_ids = self._process_next_obs(next_obs)
        
        # 10. 更新滚动状态
        rollings = self._update_rolling_state(
            rollings,
            responses_ids,
            next_obs_ids
        )
    
    return self._compose_final_output(original_left_side, original_right_side, meta_info)
```

```python:353:406:search_r1/llm_agent/generation.py
def execute_predictions(self, predictions: List[str], pad_token: str, 
                        active_mask=None, do_search=True) -> List[str]:
    """Execute predictions: parse actions and execute search if needed."""
    
    # 1. 解析动作
    cur_actions, contents = self.postprocess_predictions(predictions)
    next_obs, dones, valid_action, is_search = [], [], [], []
    
    # 2. 收集所有搜索查询
    search_queries = [content for action, content in zip(cur_actions, contents) 
                     if action == 'search']
    
    # 3. 批量执行搜索
    if do_search:
        search_results = self.batch_search(search_queries)
    else:
        search_results = [''] * len(search_queries)

    # 4. 为每个样本构建观察
    for i, (action, active) in enumerate(zip(cur_actions, active_mask)):
        if not active:
            # 非活跃样本
            next_obs.append('')
            dones.append(1)
            valid_action.append(0)
            is_search.append(0)
        else:
            if action == 'answer':
                # 回答动作 → 完成
                next_obs.append('')
                dones.append(1)
                valid_action.append(1)
                is_search.append(0)
            elif action == 'search':
                # 搜索动作 → 获取结果
                next_obs.append(f'\n\n<information>{search_results.pop(0).strip()}</information>\n\n')
                dones.append(0)
                valid_action.append(1)
                is_search.append(1)
            else:
                # 无效动作 → 提示
                next_obs.append(f'\nMy previous action is invalid...')
                dones.append(0)
                valid_action.append(0)
                is_search.append(0)
            
    return next_obs, dones, valid_action, is_search
```

```python:407:437:search_r1/llm_agent/generation.py
def postprocess_predictions(self, predictions: List[Any]) -> Tuple[List[int], List[bool]]:
    """Parse <search> or <answer> tags from predictions."""
    
    actions = []
    contents = []
            
    for prediction in predictions:
        if isinstance(prediction, str):
            # 匹配 <search>...</search> 或 <answer>...</answer>
            pattern = r'<(search|answer)>(.*?)</\1>'
            match = re.search(pattern, prediction, re.DOTALL)
            
            if match:
                content = match.group(2).strip()  # 标签内的内容
                action = match.group(1)  # 'search' 或 'answer'
            else:
                content = ''
                action = None
        else:
            raise ValueError(f"Invalid prediction type: {type(prediction)}")
        
        actions.append(action)
        contents.append(content)
        
    return actions, contents
```
