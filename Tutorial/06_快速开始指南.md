## 6.2 步骤 1: 环境准备

```bash
# 克隆项目
git clone https://github.com/your-repo/Search-R1.git
cd Search-R1

# 创建并激活环境
conda create -n searchr1 python=3.10
conda activate searchr1

# 安装依赖
pip install -r requirements.txt
pip install -e .
```

## 6.8 完整演示脚本

```bash
#!/bin/bash
set -e

echo "===== Search-R1 完整演示 ====="

# 1. 环境检查
echo "[1/6] 检查环境..."
python -c "import torch; assert torch.cuda.is_available()"
echo "✓ GPU 可用"

# 2. 下载小规模测试数据
echo "[2/6] 下载测试数据..."
if [ ! -f "data/test.parquet" ]; then
    python scripts/download_test_data.py --output ./data
fi
echo "✓ 数据就绪"

# 3. 启动检索服务器（后台）
echo "[3/6] 启动检索服务器..."
bash example/retriever/retrieval_launch_bm25.sh &
RETRIEVER_PID=$!
sleep 5

# 检查服务是否启动
curl -s http://127.0.0.1:8000/health || {
    echo "检索服务器启动失败"
    exit 1
}
echo "✓ 检索服务运行中"

# 4. 运行推理测试
echo "[4/6] 运行推理测试..."
python infer.py \
    --model_path meta-llama/Llama-3.2-3B-Instruct \
    --input_file data/test_questions.json \
    --max_turns 4

echo "✓ 推理完成"

# 5. 训练 1 个 step
echo "[5/6] 运行单步训练测试..."
timeout 300 bash train_ppo.sh || true
echo "✓ 训练测试完成"

# 6. 清理
echo "[6/6] 清理..."
kill $RETRIEVER_PID 2>/dev/null || true
echo "✓ 完成"

echo ""
echo "===== 演示完成 ====="
echo "现在你可以开始完整的训练实验了！"
```

1. 训练 loss 不下降 → 检查奖励计算
2. 检索超时 → 确认服务地址
3. OOM → 减小 batch_size
