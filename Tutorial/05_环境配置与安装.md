# 第五章：环境配置与安装

## 5.1 系统要求

### 硬件要求
| 配置 | 最低要求 | 推荐配置 |
|------|----------|----------|
| GPU | 1x RTX 3090 (24GB) | 8x A100 (80GB) |
| 内存 | 64GB | 256GB+ |
| 存储 | 500GB SSD | 2TB+ NVMe |
| 系统 | Ubuntu 20.04 / macOS | Ubuntu 22.04 |

### 软件要求
- Python 3.9+
- CUDA 11.8+ (如使用 GPU)
- PyTorch 2.0+
- Node.js (用于某些工具)

## 5.2 安装步骤

### 5.2.1 创建虚拟环境

```bash
# 使用 conda 创建环境
conda create -n searchr1 python=3.10
conda activate searchr1

# 或使用 venv
python -m venv searchr1_env
source searchr1_env/bin/activate
```

### 5.2.2 安装 PyTorch

```bash
# CUDA 11.8
pip install torch==2.4.0 torchvision torchaudio \
    --index-url https://download.pytorch.org/whl/cu118

# 或 CUDA 12.1
pip install torch==2.4.0 torchvision torchaudio \
    --index-url https://download.pytorch.org/whl/cu121
```

### 5.2.3 安装核心依赖

```bash
# Flash Attention (加速 LLM 推理)
pip install flash-attn --no-build-isolation

# Hugging Face Transformers
pip install transformers accelerate bitsandbytes

# vLLM (用于高效的 LLM 推理)
pip install vllm==0.6.3

# Ray (分布式训练框架)
pip install ray[default]

# 数据处理
pip install pandas pyarrow datasets
```

### 5.2.4 安装 veRL 和 Search-R1

```bash
# 安装 veRL
pip install verl

# 或从源码安装
git clone https://github.com/AI-MO/verl.git
cd verl
pip install -e .

# 安装 Search-R1
cd Search-R1-main
pip install -e .
```

### 5.2.5 验证安装

```bash
# 检查 Python 包
python -c "import torch; print(f'PyTorch: {torch.__version__}')"
python -c "import transformers; print(f'Transformers: {transformers.__version__}')"
python -c "import verl; print('verl installed')"

# 检查 CUDA
python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}')"
```

## 5.3 配置示例

### 5.3.1 基础配置 (train_ppo.sh)

```bash
#!/bin/bash

# ===== 环境配置 =====
export CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7
export RAY_ADDRESS="auto"

# ===== 模型配置 =====
ACTOR_ROLLOUT_REF_CONFIG="
actor_rollout_ref:
  model:
    path: /path/to/your/model  # 修改为你的模型路径
    torch_dtype: bfloat16
    use_flash_attention: true
  
  actor:
    model_class: LlamaForCausalLM
    tokenizer_class: LlamaTokenizer
    tokenizer_source: huggingface
    
    optimizer:
      type: adamw
      lr: 1e-6
      weight_decay: 0.01
      
    fsdp:
      wrap_policy: llama
      sharding_strategy: full_shard
      auto_wrap_policy: transformer_auto_wrap_policy
      
  ref:
    model_class: LlamaForCausalLM
    max_batch_size: 16
"

# ===== 数据配置 =====
DATA_CONFIG="
data:
  train_files: [data/nq_search/train.parquet]
  val_files: [data/nq_search/test.parquet]
  train_prompt_key: prompt
  val_prompt_key: prompt
  max_prompt_length: 2048
  max_response_length: 2048
"

# ===== 检索配置 =====
RETRIEVER_CONFIG="
retriever:
  url: http://127.0.0.1:8000/retrieve
  topk: 3
  timeout: 30
"

# ===== Agent 配置 =====
AGENT_CONFIG="
agent:
  max_turns: 16
  do_search: true
  stop_tokens: ['<answer>']
"

# ===== 训练配置 =====
TRAINER_CONFIG="
trainer:
  total_epochs: 1
  n_gpus_per_node: 8
  save_freq: 100
  val_freq: 50
  project_name: search_r1
  experiment_name: ppo_search_llama
"

# ===== 算法配置 =====
ALGORITHM_CONFIG="
algorithm:
  adv_estimator: grpo
  gamma: 1.0
  lam: 0.95
  epsilon: 0.2
  use_kl_penalty: true
  kl_coef: 0.04
"

# ===== 合并配置 =====
python -m verl.trainer.main_ppo \
    --config ${ACTOR_ROLLOUT_REF_CONFIG} \
              ${DATA_CONFIG} \
              ${RETRIEVER_CONFIG} \
              ${AGENT_CONFIG} \
              ${TRAINER_CONFIG} \
              ${ALGORITHM_CONFIG}
```

## 5.4 常见问题

### 问题 1: Flash Attention 安装失败

```bash
# 错误信息
error: cannot find -lcuda
```

解决方案：
```bash
pip install flash-attn --no-build-isolation --no-cache-dir
```

### 问题 2: vLLM 兼容性问题

```bash
# 检查 CUDA 版本
nvcc --version

# 安装对应版本的 vLLM
# CUDA 11.8
pip install vllm==0.4.0

# CUDA 12.1
pip install vllm==0.6.3
```

### 问题 3: Ray 连接失败

```bash
# 启动 Ray
ray start --head --num-cpus=8 --num-gpus=8

# 或使用 Ray Dashboard
ray start --head --dashboard-host=0.0.0.0
```

### 问题 4: 内存不足 (OOM)

```bash
# 使用量化
actor:
  model:
    load_in_8bit: true  # 8-bit 量化
    
# 或使用更小的模型
model:
  path: Qwen/Qwen2.5-1.5B  # 使用小模型测试
```

## 5.5 Docker ��署（可选）

### Dockerfile

```dockerfile
FROM nvidia/cuda:12.1.0-devel-ubuntu22.04

ENV DEBIAN_FRONTEND=noninteractive

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    python3.10 \
    python3-pip \
    git \
    wget \
    && rm -rf /var/lib/apt/lists/*

# 设置工作目录
WORKDIR /app

# 复制依赖文件
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY . .

# 暴露端口
EXPOSE 8000 8265

CMD ["/bin/bash"]
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  search-r1:
    build: .
    ports:
      - "8000:8000"
      - "8265:8265"
    volumes:
      - ./data:/app/data
      - ./checkpoints:/app/checkpoints
    environment:
      - CUDA_VISIBLE_DEVICES=0,1,2,3
      - RAY_ADDRESS=auto
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 4
              capabilities: [gpu]
```
